# Samm-sammult: Estonian A1 → B1

A standalone, single-file website for learning Estonian from A1 to B1. It is separate from the
Kuhu Minna app: no build step and no dependencies. Open `index.html` in a browser, or host the
file anywhere (GitHub Pages, Netlify, any static host).

- 24 units (8 each for A1, A2, B1): vocabulary, a grammar note, example sentences
- Flashcards (Estonian-first or English-first) and a quiz per unit; 80% passes the unit
- A review deck of every word you missed
- Reference: pronunciation, the 14 cases, a study plan, and free official resources
- Progress is saved in the browser's local storage
